# 홍콩 상장 기업 공시 추출 지침 ({PREFIX}, 실행 {RUN})

원본 파일: /mnt/user-data/outputs/fruiting/hk3/raw/ 의 `{PREFIX}__*.pdf` (HKEX 원본 PDF). 아래 "회사별 파일·항목"을 따른다.
다른 실행 결과 파일(extract_*_*.json)과 data/ 폴더는 열지 마라 — 독립 추출이다.

## 절대 규칙
1. PDF를 한 덩어리 평문으로 바꿔 정규식으로 숫자를 줍지 마라. pdfplumber로 해당 페이지의 표 구조(행 라벨, 열 머리 = 기간, 단위 캡션)를 유지해 읽어라. 표 추출이 깨지면 `pdftotext -layout -f N -l N` 로 그 페이지만 열 정렬을 유지해 읽고, 열과 기간의 대응을 눈으로 확인하라. 필요하면 `pdftoppm -f N -l N -r 110 -png`로 페이지 이미지를 만들어 Read 도구로 직접 보고 확인하라.
2. 줄바꿈·공백 깨짐으로 어떤 숫자가 어느 행/기간에 속하는지 모호하면 status=ambiguous + 이유. 절대 추정하지 마라.
3. 괄호 숫자 (1,234) = 음수. 단위(RMB million/thousand/yuan, US$ thousand/million, HK$)를 확인하고 아래 지정 단위로 통일(변환 시 note에 원 단위 기록).
4. 모든 값에 출처(파일명, 페이지 번호, 원문 행 라벨, 원문 열 머리, 원 단위).
5. 큰 PDF(연차보고서 수백 쪽)는 목차나 `pdftotext` 검색(grep으로 페이지 번호 찾기)으로 필요한 페이지만 열어라.

## 공통 출력 형식
`/mnt/user-data/outputs/fruiting/hk3/extract_{PREFIX}_{RUN}.json`:
{"ticker":"{PREFIX}","currency":"보고통화","items":[{"id":"Q1","period":"2026Q2","value":0,"raw":"원문 표기","unit":"","status":"ok|ambiguous|null","source":{"file":"","page":0,"row":"","col":""},"note":""}]}
- period 표기: 분기 `2026Q2`(달력 분기, 3개월), 반기 `2026H1`, 연간 `FY2025`(레노버는 3월 결산: FY2026 = 2025-04-01~2026-03-31), 시점 `2026-06-30`.
- 부문 항목 id는 `Q2_<회사 부문명 원문>` 처럼 원문 명칭을 붙인다. 5개년 항목은 `A1_2021`…`A1_2025` 처럼 연도를 붙이고 period도 `FY2021` 등.
- 값이 공시에 없으면 status=null 로 남겨라(빠뜨리지 말고).
python으로 JSON 파싱을 확인한 뒤 120단어 이내 한국어로 보고: ok/ambiguous/null 수, 모호 항목과 이유.
