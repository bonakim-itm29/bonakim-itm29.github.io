설명

앞 주차의 메가트렌드·환경분석·델파이는 '어떤 미래가 오는가'를 보았다. 이제 기업이 답할 질문은 셋이다. 무슨 기술을, 언제까지, 어떤 방식으로 확보할 것인가. 기술로드맵(TRM)은 이 세 답을 한 장의 시간표로 묶는 도구다. 질문마다 근거가 다르다는 점도 기억하자. 무엇·언제는 델파이와 시장 예측이, 어떻게는 자사 핵심역량과 자원 분석이 근거다.

clockspeed 빠른 산업: 3팀 협력의 agile 개발 필요

설명

TRM은 몇 년 뒤 제품을 준비하는 선행개발팀에 가장 잘 맞는다. 현 세대 팀은 당장의 품질과 납기가 중심이라 장기 로드맵이 덜 필요하다. 다만 제품 수명이 짧은(clockspeed가 빠른) 산업에서는 현·차·차차세대 팀이 동시에 협력하는 agile 방식이 필요하다. 교수는 한국의 방향을 '속도 → 품질 → 기술'로 제시했다.

Process funnel: 발산→수렴

앞단 (발산)

  • 제약은 적고 시나리오 다수
뒷단 (수렴)
  • 요구사항·개념 명확·안정

  • 대안은 적고 제약은 큼

Explore → Shape → Plan → Implement (Cambridge IfM)

09-1 R&D 기획 속 TRM의 자리4 / 55
설명

Cambridge IfM은 R&BD 기획을 불확실성 속에서 점차 명확하게 찾아가는 깔때기로 정의한다. 시장-기술, 요약-상세를 반복(iteration)하며 넓게 탐색한 뒤 좁혀 간다. 기획은 '지식의 집대성 작업'이다. 실무 팁: 앞단에서 대안을 너무 빨리 줄이면 좋은 기회를 놓치고, 뒷단에서도 대안을 붙들고 있으면 실행이 늦어진다.

깔때기 안의 기획 단계

  1. 1거시환경 분석

    메가트렌드·STEEP로 미래 탐색(Future Study)

  2. 2시장·경쟁 분석

    산업·시장 구조, 글로벌 경쟁, 밸류체인

  3. 3Concept Shaping

    Vision·목표, Top Brand, 역량·전략 분석

  4. 4System Tech Tree

    Target 제품을 기능·기술로 전개해 설계

  5. 5Target 도출

    Target 제품 → Target 기술 선정

  6. 6기술획득 전략

    개발/획득 방식과 Priority·Portfolio

설명

깔때기를 실제 작업으로 풀면 이 순서다. 아래에는 산업·밸류체인 분석, 기술·특허 분석, 우선순위·포트폴리오 분석이 전 과정에 깔린다(넓게 → 반복 → 적용). 예를 들어 '고령화' 트렌드에서 시작해 헬스케어 시장을 보고, Top Brand로 '가정용 진단기기'를 정한 뒤 Tech Tree로 필요한 센서·알고리즘 기술을 뽑는 식이다.

설명

해외 미래 로드맵 보고서는 대개 깔때기 앞단만 간략히 공개한다. 후보 목록이나 방향성까지만 보여주고, 실제 Target 선정과 역량 분석은 경쟁 정보라 숨긴다. 따라서 공개 보고서는 출발점일 뿐이다. 보고서에서 후보 풀을 얻되, Tech Tree와 Target 선정은 자사 역량을 넣어 직접 해야 한다.

R&BD 기획의 추세 변화

기존 기획
  • 미래 시장에서 출발
  • 시장→제품→기술→프로젝트
최근 기획
  • 미래 통찰(Future)에서 출발
  • 통찰→시장→제품→기술→프로젝트

앞단엔 넓은 미래 시각, 뒷단엔 시장성·사업성 분석 강화

09-1 R&D 기획 속 TRM의 자리7 / 55
설명

최근 기획은 시장 예측보다 한 단계 앞의 미래 통찰에서 시작한다. 기존 시장 데이터만 보면 아직 없는 시장을 놓치기 때문이다. 그래서 연구기획의 앞단(메가트렌드·시나리오)에 더 큰 비중을 둔다. 동시에 뒷단에서는 시장성·사업성 검토를 강화해, 넓게 보되 돈이 되는 과제로 좁힌다.

09-1 R&D 기획 속 TRM의 자리8 / 55
설명

산업원천기술 로드맵의 실제 추진 절차는 13단계를 크게 세 덩어리로 묶는다. ①은 1~6단계(거시환경, 산업동향, 가치사슬, 기술변화 예측, 보유역량 SWOT, 중장기 목표). ②는 7~9단계(유망기술 체계도, 선행특허 분석, 기술별 성장지표·R&D 수준). ③은 10~13단계(핵심주력제품군 선정, 산업원천기술 도출, 세부 개발전략, 보고서)다. Macro map은 제품군 수준, Micro map은 Target 제품과 원천기술 수준의 지도다.

설명

이 과목 전체의 지도다. 지금까지 배운 메가트렌드, 5 Forces, 델파이가 모두 TRM 도식화로 모인다. TRM 이후에는 내부 단계가 이어진다. 역량분석(특허 포트폴리오·지표·네트워크) → 개발/획득 기술 도출(SWOT·AHP) → R&D 기획(예산·자원 배분) → 수행관리 → 결과평가 → 결과활용이다. 각 단계 산출물이 다음 단계의 입력이 된다.

이 강의에서 기억할 것

  • TRM은 무엇을·언제까지·어떻게 개발할지 한 장에 답하는 도구
  • 기획은 발산→수렴의 깔때기: 넓게 탐색하고 반복하며 좁힌다
  • 공개 보고서는 앞단(방향)만 준다. Target·역량 분석은 직접 해야 한다
  • 최근 추세는 미래 통찰에서 출발하고 뒷단 사업성 검토를 강화

설명

Phaal 등(2004)의 틀은 세로로 Why(시장)·What(제품)·How(기술) 층을, 가로로 과거·단기·중기·장기·Vision을 둔다. 시장의 끌어당김과 기술의 밀어올림이 가운데 제품 층에서 만난다. 실무에서는 층 이름만 바꿔 쓴다. 예: 의료기기 회사라면 시장 층에 '고령 인구 증가', 제품 층에 '웨어러블 심전도기', 기술 층에 '저전력 센서'를 넣는다.

그림 아래의 번호 순서가 중요하다. 먼저 오른쪽 끝 Vision(가려는 곳)을 정하고, 왼쪽에서 현재 위치를 확인한 뒤, 그 사이의 경로(Route forward)를 그린다. 현재에서 출발해 할 수 있는 일만 늘어놓으면 점진 개선 목록이 될 뿐이다. 목표를 먼저 정해야 Gap이 보이고, Gap이 R&D 과제가 된다.

설명

지금까지 배운 도구들이 로드맵의 어느 자리에 들어가는지 보여준다. TRM은 새 분석법이라기보다 앞선 분석 결과를 한 장에 꽂는 통합 틀이다. 실무 팁: 로드맵 박스 하나하나에 근거가 된 분석 출처(예: '델파이 2차, 실현시기 중앙값 2029')를 달아 두면, 나중에 반론이 와도 설명할 수 있다.

기획은 위에서 아래로

  1. 1Market

    M1, M2: 미래 시장·니즈 (수요예측)

  2. 2Product

    P1~P4: 주력 핵심제품과 구성·기능

  3. 3Technology

    T1~T4: 제품을 구현할 기술

  4. 4R&D programmes

    RD1~RD6: 기술을 만드는 과제

  5. 5Resources

    자본·재무, 공급망, 인력·기술

09-2 TRM 아키텍처: 층 × 시간16 / 55
설명

기획 흐름은 시장 → 제품 → 기술 → R&D 순이고, 실행(화살표)은 그 반대다. 그림의 빨간 경로를 읽으면 RD1 과제가 T1을, T1이 T2로 이어져 제품 P2를 가능케 하고, P2가 시장 M2를 연다. 그래서 '시장과 제품을 먼저 정하고 기술을 선정'한다. 거꾸로 기술부터 정하면 팔 곳 없는 기술이 생긴다.

사례 · 목적→기본→n차 기능

연료전지 기능 전개

상황

목적기능을 '액체연료를 이용하여 전기를 만든다'로 매우 포괄적으로 정의했다.

한 일

기본기능 5개(산화반응, 환원반응, 이온 전달, 연료 cross-over 방지, 전기 전달)로 나누고, 이를 다시 2~5차 기능으로 전개했다.

결과

예: 이온·전자를 전달한다 → 이온 통로를 만든다 → 단면적을 넓힌다/경로를 짧게 한다. 각 기능에 목표 Spec(출력밀도, 이온전도도, crossover율)을 붙였다.

교훈

기능을 동사형으로 쪼개면 측정 가능한 목표 Spec과 요소기술이 자연스럽게 따라 나온다.

설명

목표 Spec 예시는 MEA 출력밀도(MeOH/Air, 상온 포함), 막의 이온전도도와 crossover 상한, 셀 팩의 출력밀도·에너지밀도(Wh/kg)였다. 기능마다 수치가 붙으면 다음 단계에서 '어떤 요소기술이 이 수치를 달성하는가'로 특허를 찾을 수 있다. 또 부산물을 촉매층·집전체에서 배출하는 기능처럼, 놓치기 쉬운 보조 기능도 전개 과정에서 드러난다.

사례 · 특허로 기능 전개

IBM TMR 특허 분석

상황

IBM 미국특허 5,650,958(1997)은 TMR 소자의 MR ratio를 높이는 기술이다.

한 일

주제(MR ratio 증대)를 기본기능 4개(자화방향 제어로 기록·재생, switching field 감소, edge effect 제거, 수직 전압 읽기)와 2차 기능으로 정리했다.

결과

2차 기능에 구체 방식(강자성체, 다층 박막, exchange biasing층, free층 축소, 가장자리 절연층, F-I-F 구조, tunneling)을 매칭했고 목표는 MR ratio > 28%.

교훈

특허 한 건도 기능 전개표로 바꾸면 경쟁사의 기술 방식과 목표 수준이 한눈에 보인다.
