Waterfall vs 고객개발

Waterfall·대기업
  • 고객·문제·기능이 '알려진' 상태
  • 계획(plan)을 실행하는 모드
  • 시작되면 지난 결정을 그대로 따름
  • 출시일·실행 속도에 집중
고객개발 (Blank)
  • 고객·문제는 아직 '가설' 상태
  • 반복·확장 가능한 모델을 탐색
  • 현장 검증 → 학습 → 반복
  • 실패도 탐색 과정의 일부

스타트업 ≠ 대기업의 축소판

신상품 개발 9가지 죄악 점검

  1. 1고객이 원하는 것을 '안다'고 가정하고 있지 않나?
  2. 2필요한 기능을 다 안다고 보고 전체를 개발하나?
  3. 3고객 발굴 없이 출시일에만 맞추고 있나?
  4. 4가설·검증·학습보다 실행 속도만 강조하나?
  5. 5사업계획이 시행착오가 없다고 전제하나?
  6. 6대기업 직책·계획대로 영업·마케팅을 돌리나?
  7. 7성공을 미리 가정해 채용·투자를 늘리나?
  8. 8위기 때마다 경영진 교체로 땜질하나?

고객개발 4단계

  1. 1① 고객발굴

    비전을 가설로 바꾸고 고객 반응 테스트

  2. 2② 고객검증

    반복·확장 가능한지 검증, 아니면 ①로

  3. 3③ 고객창출

    실제 고객을 모아 판매 채널로 집중

  4. 4④ 기업설립

    검증된 모델 실행 위해 기업 조직화

Leap-of-Faith 가정 2가지

가치가설
  • 고객에게 진짜 가치를 주는가?
  • 묻지 말고 가입·사용 행동을 관찰
  • 얼마나 오래, 어떻게 쓰는지 측정
성장가설
  • 새 고객이 어떻게 발견하는가?
  • 다른 고객에게 적극 전파하는가?
  • 몇 달·몇 년이 아닌 몇 주 단위 실험
