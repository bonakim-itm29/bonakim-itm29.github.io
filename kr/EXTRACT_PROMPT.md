# 한국 상장사 정기보고서 추출 지침 ({TICKER}, 실행 {RUN})

원본 파일(금감원 DART/KRX KIND 원문 HTML, UTF-8): /mnt/user-data/outputs/fruiting/kr/raw/ 의 `{PREFIX}__*.htm`
- `{PREFIX}__H1_2026__*.htm` 2026년 반기보고서(2026-06-30), `{PREFIX}__Q1_2026__*.htm` 1분기보고서
- `{PREFIX}__FY2025__*.htm` 2025년 사업보고서, `{PREFIX}__FY2022__*.htm` 2022년 사업보고서
다른 실행 결과 파일(extract_*_*.json)과 data/ 폴더는 열지 마라 — 독립 추출이다. 임시 파일은 /tmp/kr_{TICKER}_{RUN}/ 에만.

## 절대 규칙
1. HTML을 평문으로 바꿔 정규식으로 숫자를 줍지 마라. BeautifulSoup(lxml)/pandas.read_html로 `<table>`의 행 라벨·열 머리(기간: "제58기 반기 3개월", "누적" 등)·단위 캡션("(단위 : 백만원)")을 유지해 읽어라. 표 밖 수치는 한 문장 안에 온전히 있을 때만.
2. 연결(consolidated) 재무제표 기준. 별도 재무제표와 섞지 마라.
3. 기간·단위·연결/별도가 모호하면 status=ambiguous + 이유. 절대 추정하지 마라.
4. 금액은 KRW 백만원으로 통일(원문이 원·천원이면 변환하고 note). 주식 수는 주 단위.
5. 모든 값에 출처(파일명, 표 순번(0부터), 원문 행 라벨, 원문 열 머리, 단위).

## 추출 항목

- Q1 매출액 / Q3 영업이익 / Q5 지배기업 소유주지분 순이익 / Q7 기본·희석 주당이익(보통주, 원)
- Q2 부문별 매출·영업이익(부문 정보 주석 또는 사업의 내용의 부문 표, 회사 부문명 그대로, 3개월 값이 있으면 3개월, 없으면 누적이라고 명시)
1분기(분기보고서) 같은 항목(Q1, Q3, Q5)도 period=2026Q1 로.

재무상태(2026-06-30, 연결): B1 현금및현금성자산 / B2 단기금융상품·단기상각후원가금융자산·단기당기손익-공정가치금융자산 등 현금성 투자(행 이름 그대로 각각) / B3 차입 항목(단기차입금, 유동성장기부채, 사채, 장기차입금 등 각각) / B5 자산총계 / B6 자본총계와 지배기업 소유주지분
주식·주주환원:
