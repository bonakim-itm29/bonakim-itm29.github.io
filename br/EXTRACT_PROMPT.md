# 브라질 ADR 기업 공시 추출 지침 ({T}, 실행 {RUN})

원본: /mnt/user-data/outputs/fruiting/br/raw/{T}/ 아래 접수번호(accession) 폴더별 SEC 6-K 원문(htm + 페이지 이미지 jpg). 아래 "회사별 파일"에서 각 폴더의 역할을 확인한다.
다른 실행 결과 파일(extract_*_*.json)과 data/ 폴더는 열지 마라 — 독립 추출이다.

## 절대 규칙
1. HTML을 한 덩어리 평문으로 바꿔 정규식으로 숫자를 줍지 마라. BeautifulSoup(lxml)/pandas.read_html로 `<table>`의 행·열(기간 열 머리, 단위 캡션)을 유지해 읽어라.
2. 표가 jpg 이미지로만 있으면 Read 도구로 이미지를 직접 보고 읽어라(htm 안 <img src> 순서가 페이지 순서). 이미지 숫자는 행 라벨·열 머리와 함께 눈으로 확인한다.
3. 어떤 숫자가 어느 행·기간·단위에 속하는지 모호하면 status=ambiguous + 이유. 절대 추정·계산으로 메우지 마라. 공시에 없으면 status=null.
4. 괄호 (1,234) = 음수. 단위(R$ million/thousand, US$ million/thousand, R$ billion)를 확인하고 아래 지정 단위로 통일(변환 시 note에 원 단위 기록). 브라질식 표기(1.234,5)는 소수점·천 단위 구분을 확인한다.
5. 모든 값에 출처(file = 폴더/파일명 또는 이미지 파일명, row = 원문 행 라벨, col = 원문 열 머리, page = 이미지면 파일명).
6. 회사가 제시한 "조정(adjusted)·경상(recurring)" 지표는 명칭과 정의를 그대로 기록하고 회계 수치와 구분한다.

## 기간 표기
분기 `2026Q2`(4~6월), `2026Q1`, 전년 동기 `2025Q2`, 반기 `2026H1`, 시점 `2026-06-30`. 같은 표에 있으면 세 분기 모두 기록.

## 출력
`/mnt/user-data/outputs/fruiting/br/extract_{T}_{RUN}.json`:
{"ticker":"{T}","currency":"보고통화","items":[{"id":"Q1","period":"2026Q2","value":0,"raw":"원문 표기","unit":"","status":"ok|ambiguous|null","source":{"file":"","page":"","row":"","col":""},"note":""}]}
부문·세부 항목 id는 `Q2_<원문 부문명>` 식. python으로 JSON 파싱 확인 후 120단어 이내 한국어 보고(ok/ambiguous/null 수, 모호 항목과 이유).

## 항목 A — 비금융 기업(VALE, PBR, ABEV, SBS, ERJ, AXIA)
- Q1 매출(net operating revenue) / Q2_<부문> 부문 매출(있으면) / Q3 회사 제시 조정 EBITDA(명칭 그대로) / Q4 영업이익 또는 EBIT / Q5 지배주주 귀속 순이익 / Q6 회사 제시 조정·경상 순이익(있으면) / Q7 주당순이익(기본) / Q8 영업활동 현금흐름 / Q9 설비투자(capex, 회사 제시값과 현금흐름표 행 이름) / Q10 회사 제시 FCF(정의 포함, 있으면)
- B1 현금및현금성자산 / B2 기타 단기 금융투자(행 이름 그대로 각각) / B3 총차입(차입금·사채·debentures 등 유동·비유동, 리스부채는 따로) / B4 회사 제시 순부채(정의 포함) / B5 총자산 / B6 지배주주지분
- S1 유통주식 수(자기주식 제외, 보통주·우선주 구분, 기준일) / S2 ADR 1주당 원주 비율(있으면)
- R1 해당 분기·반기에 선언한 배당·자본이자(JCP) 총액과 주당 금액 / R2 자사주 매입(있으면)
- 회사별 운영 지표(있는 것만): VALE 철광석 생산·판매량(백만 톤), 철광석 실현가격(US$/t), C1 원가 / PBR 석유·가스 생산(천 boed), 평균 Brent, 실현 가격 / ABEV 총 판매량(백만 hl) / SBS 청구 물량, 요금 조정 / ERJ 항공기 인도 대수(사업부별), 수주잔고(US$) / AXIA 발전·송전 수익 구분
## 항목 B — 금융(ITUB, BBD, NU)
- Q1 회계상 순이익 / Q2 회사 제시 경상(recurring/managerial)·조정 순이익(명칭 그대로) / Q3 ROE(회사 제시, 연율) / Q4 순이자이익 또는 금융마진(NII, 명칭 그대로) / Q5 수수료·서비스 수익 / Q6 대손비용·신용손실 충당금 비용 / Q7 효율성 지표(efficiency ratio, 있으면) / Q8 주당순이익
- B1 대출 포트폴리오 총액 / B2 90일 이상 연체율(NPL 90) / B3 총자산 / B4 지배주주지분 / B5 CET1(보통주자본비율) / B6 예금 총액(있으면)
- S1 유통주식 수(자기주식 제외, 보통주·우선주 또는 Class A·B 구분, 기준일)
- R1 해당 기간 선언한 배당·JCP 총액과 주당 금액 / R2 자사주 매입
- NU만: 고객 수(백만), 총매출(revenue), 조정 순이익
